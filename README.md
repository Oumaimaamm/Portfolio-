# Oumaima Amara — Portfolio

Static portfolio source: HTML, CSS and JavaScript, with project images, résumé and NOMAÉ case study.

## Deploy on Vercel

1. Import `Oumaimaamm/Portfolio-` into Vercel.
2. Keep the Root Directory at the repository root.
3. Use the **Other** framework preset. The included `vercel.json` sets the output directory to `dist` and skips the build command.
4. Deploy. No dependencies or environment variables are required.

## Local preview

Run `python -m http.server 8000 --directory dist`, then open http://localhost:8000.

## Editing

- `dist/index.html`: content and markup
- `dist/style.css`: design and responsive layout
- `dist/script.js`: theme toggle and clock
- `dist/assets/`: images and PDF documents

The website files are copied unchanged from the existing portfolio.
